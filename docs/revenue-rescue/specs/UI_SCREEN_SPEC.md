# UI Screen Specification

## Dashboard
Headline cards:
- Potential value at risk
- Confirmed recovered
- Outstanding action value
- RED actions
- HOLD items

Charts/tables:
- Recovery over time
- Open findings by rule
- Top outstanding actions

## Import Centre
- Upload button
- Source-type selector
- Previous imports
- Status, row counts and error counts

## Mapping Wizard
- Source header
- Example value
- Canonical field dropdown
- Required/optional indicator
- Validation warnings

## Validation Results
Tabs: Valid / Invalid / Hold
User sees exact reason and affected row.

## Findings
Sortable/filterable table, quick assignment and bulk non-destructive actions where safe.

## Finding Detail
Evidence-first layout. No claim of certainty beyond the source data.

## Action Queue
Optimised for daily operations, with overdue exceptions at top.

## Recovery
Confirmation form with amount, date, note and evidence reference.

## Audit
Read-only chronological events with filters.

## Users
Role assignment with least-privilege defaults.
