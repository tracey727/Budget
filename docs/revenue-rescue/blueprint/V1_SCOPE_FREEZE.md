# V1 Scope Freeze — ON TRACK Revenue Rescue™

## Objective
Ship a small, commercially testable product quickly without allowing the build to expand into a general business operating system.

## Core user journey
Upload → Map → Validate → Detect → Prioritise → Action → Confirm recovery → Report.

## V1 includes
- Secure tenant/user model
- CSV/XLSX import
- Mapping templates
- Deterministic validation
- Allied-health rule pack
- Explainable findings
- RED/AMBER/GREEN/HOLD action queue
- Assignment and due dates
- Recovery confirmation
- Dashboard and exports
- Audit trail
- Synthetic demo tenant

## V1 excludes
- Banking connections
- Real-time PMS/accounting integrations
- Automatic invoices, charges or refunds
- Automated collections
- AI-generated financial conclusions
- Clinical decisions
- Native iOS/Android apps
- Email/Slack triage
- Stock Sense features
- ScriptGuard features
- Full Psychological Command Centre features
- Multi-industry packs

## Change-control rule
Any proposed feature outside the V1 list is placed in the post-V1 backlog unless it is required for security, data integrity, legal compliance, or the core upload-to-recovery flow.
