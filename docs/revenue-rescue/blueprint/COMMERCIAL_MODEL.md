# Commercial Model — Working Blueprint

## Positioning
Revenue Rescue is sold as operational leakage detection and action software, not as an accounting, legal, clinical or debt-collection service.

## Primary sales message
**Imagine how much money you can save with this program by things not falling through the cracks.**

Supporting wording should remain evidence-based: the system identifies potential leakage and tracks confirmed recovery; it does not promise that every flagged amount will be recovered.

## Initial offer structure to test
### Pilot
- Fixed-duration pilot
- One organisation / limited users
- Assisted import setup
- Baseline measurement
- Weekly review of findings
- End-of-pilot recovery/action report

### Paid plans — hypothesis to validate
Suggested testing range, not a guaranteed market price:
- Small practice: AUD $299–$499/month
- Larger or multi-site: AUD $799–$1,499/month
- Enterprise: negotiated

## Commercial proof points to collect
- Time to first useful finding
- Total value reviewed
- Confirmed recovered value
- Number of unresolved actions closed
- Cancellation slots recovered
- Invoices progressed
- Staff time saved in manual checking

## Avoid
- Guaranteed savings claims
- “We will recover $X” claims before evidence
- Treating estimated value as realised revenue
