# 30-Day Pilot Plan

## Goal
Prove that Revenue Rescue can turn a customer's existing exports into useful, explainable actions and measurable confirmed recovery with low setup effort.

## Week 0 — Setup
- Sign pilot terms.
- Create tenant and authorised users.
- Identify supported exports.
- Use minimum required fields.
- Confirm data handling and retention.
- Establish baseline period.

## Week 1 — First import
- Upload and map.
- Resolve invalid/HOLD rows.
- Run rules.
- Review first findings with authorised customer representative.

## Week 2 — Action workflow
- Assign top RED/AMBER findings.
- Record actions.
- Refine only configuration thresholds, not core rule meaning, unless a formal rule version change is required.

## Week 3 — Recovery tracking
- Confirm recoveries only where customer provides evidence.
- Record dismissed findings and reasons.
- Measure staff effort.

## Week 4 — Outcome review
Report:
- imports processed
- findings by rule
- actions closed
- potential value identified
- confirmed recovered value
- HOLD/dismissed values
- user feedback
- decision on paid continuation

## Pilot pass indicators
No guaranteed thresholds. The commercial decision should consider both measurable recovery and operational usefulness.
